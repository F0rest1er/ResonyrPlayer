# Создание тем оформления для Resonyr

Тема в Resonyr — это простой ZIP-архив со стилями CSS, манифестом и опциональными картинками или шрифтами. Тема подключается поверх стандартных стилей, поэтому можно как слегка подправить цветовую гамму, так и полностью преобразить интерфейс.

## Быстрый старт

1. Создайте рабочую папку темы на компьютере.
2. Создайте в ней два обязательных файла: `manifest.json` и `theme.css`.
3. При желании добавьте файл превью `preview.png` и папку `assets` с вашими шрифтами или фонами.
4. Выделите файлы **внутри папки** и запакуйте их в обычный ZIP-архив.
5. Войдите в Resonyr под учетной записью администратора.
6. Откройте раздел «Пользователи» и нажмите кнопку **«↑ Тема»**.
7. Загрузите полученный ZIP-файл.
8. Переключите оформление в выпадающем списке «Оформление» в верхней панели.

### Важно: структура архива

Файлы должны находиться в корне архива, без промежуточной папки:

Правильно:
```text
my-theme.zip
├── manifest.json
├── theme.css
├── preview.png
└── assets/
    ├── background.webp
    └── font.woff2
```

Неправильно:
```text
my-theme.zip
└── my-theme/
    ├── manifest.json
    └── theme.css
```

## Требования и безопасность

- Размер архива — до 12 МБ (в распакованном виде — до 20 МБ).
- Не более 100 файлов внутри архива.
- Запрещены директивы `@import`, внешние ссылки (`http://`, `https://`), `data:`, `javascript:` и симлинки. Все картинки и шрифты должны лежать локально в папке `assets/`.
- Разрешенные форматы в `assets/`: PNG, JPEG, WebP, GIF, WOFF, WOFF2, TTF, OTF.
- Если тема с таким `id` уже загружена, перед загрузкой обновленной версии удалите старую либо увеличьте идентификатор.

## Файл manifest.json

```json
{
  "id": "dark-forest",
  "name": "Dark Forest",
  "version": "1.0.0",
  "author": "Ваше имя",
  "preview": "preview.png"
}
```

- `id`: уникальный идентификатор (только строчные латинские буквы, цифры и дефис, до 50 символов).
- `name`: название темы, которое увидят пользователи в списке.
- `version`: номер версии темы.
- `author`: автор темы.
- `preview`: имя файла превью (опционально, используйте `preview.png`).

## Основные CSS-переменные

Проще и надежнее всего настроить тему через переопределение стандартных переменных. Они автоматически изменят все элементы плеера:

```css
:root {
  --background: #f4f5f8;
  --surface: rgba(255, 255, 255, 0.86);
  --surface-solid: #ffffff;
  --text: #171827;
  --muted: #6d7084;
  --line: rgba(31, 34, 61, 0.11);
  --accent: #6558f5;
  --accent-hover: #5144df;
  --accent-soft: rgba(101, 88, 245, 0.13);
  --secondary: #00a99d;
  --shadow: 0 18px 48px rgba(42, 39, 87, 0.12);
}
```

| Переменная | Назначение |
|---|---|
| `--background` | Основной фон всей страницы |
| `--surface` | Полупрозрачный фон карточек, боковой панели и плеера |
| `--surface-solid` | Непрозрачные поверхности: модальные окна, выпадающие списки |
| `--text` | Основной цвет текста |
| `--muted` | Вторичный текст, подписи, неактивные иконки |
| `--line` | Цвет рамок, разделителей и границ |
| `--accent` | Главный акцентный цвет: ссылки, активные кнопки, полоса прогресса |
| `--accent-hover` | Цвет акцентных кнопок при наведении |
| `--accent-soft` | Мягкий полупрозрачный акцентный фон |
| `--secondary` | Дополнительный цвет: логотип, индикаторы статуса |
| `--shadow` | Тени панелей и всплывающих окон |

## Поддержка темного и светлого режимов

Пользователь может явно включить светлый или темный режим в шапке, либо оставить системный. Опишите оба состояния:

```css
:root {
  --background: #f4f5f8;
  --surface: rgba(255, 255, 255, 0.86);
  --surface-solid: #ffffff;
  --text: #171827;
  --muted: #6d7084;
  --line: rgba(31, 34, 61, 0.11);
  --accent: #6558f5;
  --accent-hover: #5144df;
  --accent-soft: rgba(101, 88, 245, 0.13);
  --secondary: #00a99d;
  --shadow: 0 18px 48px rgba(42, 39, 87, 0.12);
}

:root[data-color-mode="dark"] {
  --background: #11121a;
  --surface: rgba(27, 29, 42, 0.9);
  --surface-solid: #1b1d2a;
  --text: #f5f5fb;
  --muted: #9b9eb1;
  --line: rgba(226, 228, 255, 0.1);
  --accent: #8b80ff;
  --accent-hover: #a097ff;
  --accent-soft: rgba(139, 128, 255, 0.16);
  --secondary: #3ed7c8;
  --shadow: 0 20px 50px rgba(0, 0, 0, 0.3);
}

@media (prefers-color-scheme: dark) {
  :root:not([data-color-mode]) {
    --background: #11121a;
    --surface: rgba(27, 29, 42, 0.9);
    --surface-solid: #1b1d2a;
    --text: #f5f5fb;
    --muted: #9b9eb1;
    --line: rgba(226, 228, 255, 0.1);
    --accent: #8b80ff;

    --accent-soft: rgba(139, 128, 255, 0.16);
    --secondary: #3ed7c8;
    --shadow: 0 20px 50px rgba(0, 0, 0, 0.3);
  }
}
```

## Подключение картинок и шрифтов

Файлы из папки `assets/` подключаются относительно файла `theme.css`:

```css
@font-face {
  font-family: "CustomSans";
  src: url("assets/font.woff2") format("woff2");
  font-display: swap;
}

.page {
  font-family: "CustomSans", sans-serif;
  background-image: url("assets/background.webp");
  background-size: cover;
  background-position: center;
}
```

## Основные классы интерфейса (БЭМ)

Интерфейс плеера сверстан по БЭМ. Ключевые блоки:

- `.page` — общая страница и фон.
- `.glass` — подложка со стеклянным эффектом (blur).
- `.app` — сетка интерфейса (боковое меню + контент + нижний плеер).
- `.sidebar` — боковая панель навигации.
- `.nav__item`, `.nav__item--active` — пункты меню.
- `.toolbar` — верхняя закрепленная панель (поиск, темы, профиль).
- `.search__input` — поле поиска.
- `.library` — основной контейнер медиатеки.
- `.folder` — карточка папки с музыкой.
- `.playlist-card` — карточка плейлиста в режиме сетки.
- `.playlist-card--list` — карточка плейлиста в режиме списка.
- `.track` — строка трека в таблице.
- `.track--active` — текущий играющий трек.
- `.track__favorite--active` — активная кнопка «сердечко» (в избранном).
- `.player` — нижняя панель плеера.
- `.cover` — блок обложки текущего трека в плеере.
- `.play-button` — круглая кнопка воспроизведения/паузы.
- `.progress__range` — ползунок перемотки трека.
- `.volume__range` — ползунок громкости.
- `.modal` — всплывающие модальные окна.
- `.file-list`, `.file-row` — строки файлового менеджера.

## Чек-лист перед загрузкой

- Файлы `manifest.json` и `theme.css` лежат прямо в корне ZIP-архива.
- Текст хорошо читается и контрастирует с фоном.
- Все изображения и шрифты лежат в папке `assets/` и подключены через относительные пути `url("assets/...")`.
- Нет внешних ссылок и `@import`.
