Загрузить тему

Режим меняет только светлую/тёмную палитру. Тема — ZIP-пакет полного оформления.

Как создать свою тему

Положите в корень ZIP файлы:

manifest.json
theme.css
preview.png (необязательно)
assets/ (необязательно)

manifest.json:

{"id":"my-theme","name":"Моя тема","version":"1.0.0","author":"Имя"}

В theme.css переопределяйте --background, --surface, --text, --muted, --line, --accent, --accent-hover, --accent-soft, --secondary и --shadow. ID — строчные латинские буквы, цифры и дефисы. Внешние URL и @import запрещены; ресурсы храните в assets/.

Облачный источник

Получите токен с правом cloud_api:disk.read в Яндекс OAuth и вставьте сюда. Client Secret для этого способа не нужен. Токен хранится зашифрованным на вашем сервере; после его истечения источник нужно подключить заново.

Google, Dropbox и OneDrive откроют страницу подтверждения доступа. Яндекс Диск подключается по токену. Используйте HTTPS, чтобы защитить учётные данные при передаче.
